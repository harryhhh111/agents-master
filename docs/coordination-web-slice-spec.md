330 项全量测试与 typecheck 均通过，核心真实浏览器流程也已通过。**完整第二切片尚未完成**：后台内部工具协议仍在内存，

## 本轮交付

在现有 Web 中增加显式启用的协调联调入口，而非改动生产服务。会话列表置顶主 Agent，
显示一个工作项目群；群默认路由工作项目 Agent，明确选择/@主 Agent 时交主 Agent。
派工、问题和结果在群内可见，完成/待答回传主入口；主聊和群聊均能关联回答同一待决问题。
提供持久状态与取消控制，刷新、切换会话和重连不串消息、不重复执行、不丢待答项。

接入真实可配置的模型工具协议适配器，验证使用注入的合成模型；不做自然语言正则派工。
主 Agent 的工具面只含目录/状态、受限委派、回答问题与请求取消，不开放 shell、文件或路径工具。
领域判断通过适配已有 AgentCore 的受限回合能力实现，不能直接开放旧 11 个工具及其默认
memory/state/执行器，也不能另造一套泛用 harness。领域只看本群与委派所需上下文；
主会话主人背景不自动转发。主 Agent 保持短回合，后台领域工作不得阻塞主聊。

执行端继续使用明确标注的合成执行器：可以测试排队、追问、完成、失败与取消，但不能表示
真的检查过 stock_data 或读取了项目文件。真实 CLI、真实项目数据外发和生产迁移均不在此轮。

## 实现约束

- 一个持久事务拥有者，复用已有协调表；如新增协议记录/路由字段，显式版本化，不在读取时
  偷加列。旧默认 Web 路径继续原样可用；新入口不得自动升级旧库或默默使用生产数据目录。
- 先持久准入，再异步处理。上下文按会话/来源锚点冻结；前台一个提交队列，后台独立。
  工具调用 ID、参数、结果和源回合可恢复；已提交的委派/回答/取消不因模型重试而再次执行。
  参数白名单、来源、项目绑定、调用数量与时限均由宿主检查；工具结果配对合法。
- 用户正文、模型自述或客户端作者字段均不能伪造可信来源。模型提交前的“已完成”不作状态
  证明；可操作卡片展示宿主持久状态，并明确模拟执行范围。模糊意图先提问。
- 两处回答走同一问题版本与来源事件校验。取消先持久请求，确认停止后才终态；未知不自动重放。
- 会话级 history/status/events 与 API 均复用登录、同源写保护、输入限制和安全错误处理。
  切换会话、历史请求返回乱序、SSE 重放/重连、退出登录时的旧回调不得污染当前界面。
- 已有登录、主人上下文、中文输入法、多行输入、滚动与发送失败重试体验不回退。
- 完成/问题回传仍走持久 outbox 及有界公平安全点，不依赖浏览器在线，不启动第二个主脑。
- 不读取生产库或个人聊天验证。测试统一 `DOTENV_CONFIG_PATH=/dev/null`；临时私有数据目录，
  合成 owner context、注入模型、模拟执行器，禁止通过导入默认配置意外加载 `.env`。

## 验收

除全量测试和 typecheck，需在本机临时服务上做真实浏览器验收：登录、会话切换、
主聊委派、后台未完成时继续主聊、群内追问/回答、主入口结果回传、刷新恢复、取消与未授权访问。
浏览器只能访问本轮临时 loopback 服务，不访问现有服务或个人数据。
模型端测试覆盖合法/非法工具参数、超时、重复调用、恢复配对与上下文隔离；不能把 mock
测试称为当前 DeepSeek 服务的 live 验收。实际模型与生产启用另列待验收项。

按 AGENTS.md 由 Codex 原生 CLI 实现、Kimi 原生 CLI 限定范围独立复核，保留原始产物。
不自动 commit/push、安装依赖、迁移生产数据、重启或修改 Tailscale/外部服务。
