## stock_data — 多市场股票数据 + 量化分析系统

**一句话**：拉取 A 股 / 港股 / 美股基本面与行情数据，入 PostgreSQL，上层做选股、个股分析、回测和模拟盘。

### 技术栈
- 后端：Python 3.10+ / PostgreSQL 16+，数据源为东方财富（akshare）、腾讯行情、SEC EDGAR
- 前端：React 18 + Vite + shadcn/ui + ECharts + TanStack Query（`frontend/`，部署到 Cloudflare Pages）
- Web API：FastAPI（`web/`，纯 JSON 接口）

### 分层结构
- **根目录** `config.py` / `db.py`：全局配置（`STOCK_` 前缀环境变量）+ 连接池 / UPSERT（COALESCE 防 None 覆盖）

- **`quant/` 量化层**：`screener/`（多因子选股，5 个预设）、`analyzer/`（个股四维分析）、`backtest/`（因子回测 + 复合策略引擎）、`paper/`（模拟盘，已开工）、`checks/`
- **`scripts/`**：SQL DDL、回填 / reparse / 归档脚本；**`tests/`**：13 个测试文件（pytest）

修好了。总结一下：

**问题不是数据缺失** — 数据库里 `NVDA / NVIDIA CORP / US` 一直都在。

**真正原因**：搜索接口 `web/wrappers/analyzer_wrapper.py` 用的是 PostgreSQL 的 `LIKE`，它**区分大小写**。你输入小写 `nv`，匹配不到大写的 `NVDA` / `NVIDIA CORP`，只匹配到了名称里含小写 "nv" 的 Kenvue、Invesco 等，所以看不到英伟达。

**修复**：把两处搜索条件从 `LIKE` 改成 `ILIKE`（不区分大小写），现在小写 `nv` 能正常搜出 `NVDA`，见上面验证结果。
