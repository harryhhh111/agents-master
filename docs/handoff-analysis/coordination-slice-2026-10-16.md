# 持久协调层离线切片：实现与独立验收

日期：2026-10-16。范围见 [切片规格](../coordination-slice-spec.md)。

结论：Codex 原生 CLI 实现，Kimi Code 独立复核最终**接受限定的离线假执行器切片**。
协调者核对最终文件哈希、命令结果与范围；不把此结果外推为真实 Agent、浏览器或隔离验收。
用户已授权本轮所需源码、规格与合成测试经当前 `api.kimi.com` 配置复核，不包含凭据、个人
聊天、生产数据库或真实项目内容。

## 交付

- 现有消息表仍是唯一消息真相，同一 SQLite 连接提交用户输入、委派、运行、问题与回传事务。
- 主聊/群聊读取与领取隔离；冻结上下文、来源绑定的幂等委派与回答，拒绝呈现消息再触发执行。
- 后台执行与前台回复分离；持久等待回答、取消确认、迟到结果围栏、重启 unknown 而非自动重放。
- 独立 outbox 与安全点汇报；有界公平、失败可重试、过期结果不误投，遗留 timer/domain 不参与。
- 显式合成旧库迁移：一致备份、完整性校验、事务回滚、版本与旧写者兼容保护。
- 无参数 FAKE 演示；仅创建私有临时目录并在退出时清理，不读取真实项目或模型配置。

本轮应用修改限于 `src/main/inbox.ts` 及新增 `src/main/schema.ts`、`src/main/coordination/`，
新增三个 coordination 测试文件与 `scripts/smoke-coordination.ts`。既有 dirty 的 Web、
frontbrain、runtime 等改动保留。未 commit/push、未部署/重启、未迁移生产库。

## 复核校正与过程记录

- 初轮独立报告暂缓，理由是迁移测试与演示缺失；这是并行实现期间的过时观察。最终冻结版本
  已具备这两项，并经复核撤销暂缓；不是初轮报告后又新增一套实现。原始报告不改写。
- 最终报告把迁移测试概括为“6 项”，准确的展开用例数是 **14**（包含参数化拒绝案例）；
  定向总数 51、全量总数 299 不受此措辞影响。
- 保留一个非阻塞耦合项：假前台取消方法使用固定 `fake-work` 字面量。当前范围正确；以后
  泛化项目绑定时应统一常量/绑定来源。本轮不把它扩展为通用取消 API。
- 迁移连接持有排他锁，须关闭再重新打开；已写入规格运行限制。连接标记只是旧版本兼容保护，
  不是安全沙箱。
- 最初若干全量测试未禁用既有 `dotenv/config` 导入，可能自动加载 `.env`，偏离“不读取配置”的
  验证约束；未查看、输出、复制配置值或发起模型请求。已向用户披露，最终双方复验统一禁用加载。
- 保留首次 tsx IPC / 子进程捕获的环境失败和中间断言失败；最终用 `node --import tsx`，
  子进程测试使用私有输出文件，不跳过真实用例。复核产生的测试快照一度被 Vitest 误收集，
  已仅改名该证据副本并完整复跑，不修改应用测试来隐藏失败。
