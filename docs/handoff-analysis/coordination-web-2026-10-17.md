# 协调 Web 联调切片：实现与验收记录

日期：2026-10-17。规格见 [第二切片](../coordination-web-slice-spec.md)。

## 范围与当前结论

本轮交付独立启用的合成联调入口，不替换现有聊天网站，不读取生产库或真实项目，
不迁移生产数据、不部署、不 commit/push。Codex 原生 CLI 实现，Kimi 原生 CLI 在用户明确
授权的源码、规格及合成测试范围内复核。原有 dirty worktree 保留。

Kimi 最终结论：**限定联调范围通过，未发现阻塞问题**。协调者接受该限定结论；这不等于
下文列出的完整领域适配、真实模型与生产启用已经完成。

已实现主聊置顶/工作群切换、普通群聊默认领域判断、群内 `@main`、受限协调工具、
问题回答/取消卡片及持久回传。普通群聊与主聊使用相同的来源绑定派工入口；澄清不会被
强行改成派工。主聊与群聊共用一个轮转前台处理队列，后台独立，不等待浏览器在线才能回传。

前台模型协议持久记录尝试数、调用及结果，工具副作用与结果共用事务。非法协议保留证据，
安全结束该输入而不永久卡住后续对话；临时网络错误只允许有界显式重试。操作卡片以持久状态
为准。保存的主人背景在启动/保存/重开后用于主聊，但不自动加入群聊、群内主 Agent 或领域运行。

## 已验证与待验证

- 协调者冻结代码后全量复跑：**25 个测试文件 / 330 项通过**。
- 实现方最后定向：**7 文件 / 94 项通过**，typecheck、diff check 通过。
- 协调者真实 Chromium 烟测通过：登录、普通群聊派工、输入答案等待超过两次轮询、切换会话
  保留答案、群内提交回答、主聊结果回传、刷新、退出后未授权接口 401。
- Kimi 冻结版本独立复跑：**94 项定向、330 项全量及 typecheck 通过**，复核前后源码哈希不变。
  独立浏览器最终一轮通过主聊/群聊派工、后台挂起时继续主聊、两处回答、草稿保留、取消及停止
  确认、待答问题跨重启、未知运行不重放、登录退出与主人背景隔离。
- 完整的延迟响应乱序、断网/SSE 重连、中文输入法与滚动压力场景没有穷尽浏览器验证；现有回归
  测试保留，但不能把“未覆盖”写成浏览器已通过。真实模型、真实执行仍未验证。
  群内 `@main` 通过模型工具回答/取消也未做浏览器验证；已覆盖的是两处卡片控制入口。

所有验证使用 `DOTENV_CONFIG_PATH=/dev/null`、注入合成模型与新建私有数据目录。
实际浏览器使用 `/var/tmp` 下本次生成的目录、临时回环端口及全新浏览器会话，不读取个人浏览器。
本机 `/tmp/.git` 触发既有路径保护，不为测试放宽生产检查。首次浏览器脚本的字符串表达式触发
CSP 禁止 eval；改成 locator 断言后通过，未放宽 CSP。失败产物保留。

独立扩展脚本的前四次运行因夹具问题中断：状态字符串解析、异步页面加载的等待条件、选中已回答
问题、以及误以为重启必然需要再次登录。修正仅发生在 gitignored 测试夹具，应用代码保持冻结。
最终证据为 `final-review/raw-browser-full-5.log`；此前日志保留，不用后一次结果覆盖失败历史。
多任务回传用例按合成正文计数，A/B 的正文标签并不单独证明任务身份绑定；来源、问题版本与恢复
运行的绑定以定向事务测试为准。验收不能只据“完成”字样判定原任务身份。

## 必须保留的限制

1. **不是完整 AgentCore 适配**：目前只共享有界迭代/工具结果配对基础函数，没有将旧 AgentCore
   的持久领域判断完整接入。旧默认工具面没有开放；不能把这一点写成领域适配已经完成。
2. **后台内部协议暂不恢复**：运行上下文、已提交问题/结果及 outbox 持久；后台内部工具回合
   仍在内存，提交前中断的问句可能丢失。重开后未知运行标记 unknown/interrupted，绝不自动重放。
   完整后台协议日志仍是第二切片的缺项，不能宣称所有层级均可恢复。
3. 配置模型适配器已可执行，但本轮只以注入响应验证协议，**未调用真实 DeepSeek 服务**。
   CLI、真实项目数据及完整隔离门槛仍未接入。展示中的 FAKE/模拟标注是实际能力边界。
4. 新入口只创建/打开显式标记的私有 v2 预览库，不提供生产 v1→v2 迁移。一个目录只允许单个
   预览 host；进程内单前台不是多进程主节点锁。群聊按钮/任务卡片是联调 UI，不是最终任务 Tab。
